About np-track

The fuller picture behind a profile.

np-track brings the visible pieces of a PlayStation history together, then makes the patterns easier to explore.

●

Right now

Presence, platform, and the current game when the profile lets PSN share them.

◷

Time in context

Total playtime, first and last played dates, and play counts across the visible history.

↗

The games that won

A visual top ten reveals the titles that claimed the largest share of the journey.

◇

Trophy momentum

Overall trophy totals and game-level completion progress appear alongside playtime.

⌕

A library to explore

Search instantly, then reorder the collection by time, recency, or title.

⌁

Visibility comes first

Only information PSN makes visible to the requesting account can appear. Nothing is guessed.

Presence has limits

Online, playing, or unavailable.

np-track can show online status and the current game when PSN returns them. “Appearing Offline” is not exposed as a separate state, so it looks the same as being offline.

Temporary access

An override for failed authentication.

The search page can use a temporary NPSSO value for one request. np-track does not save it, place it in the URL, or read from and write to shared profile cache while it is in use.

An NPSSO value is equivalent to a password. Only enter it on a deployment you control and trust.
