Can it detect Appearing Offline?

np-track can show online status and the current game when PSN returns them. If a profile appears offline, the user may be hiding their activity status or may actually be offline; PSN does not expose those as separate states.

What is the NPSSO override?

The search page can use a temporary NPSSO value without placing it in the URL or saving the secret. The returned profile data may be kept on this device for offline use and can be removed from Settings.

An NPSSO value is equivalent to a password. Only enter it on a deployment you control and trust.

Why can a renamed account fail?

Some Sony profile endpoints retain different name mappings after an online ID change. Add the previous ID in Settings so np-track can resolve the stable numeric account ID. You can also search the previous ID directly, which may return the account under its current name. Previous IDs are stored locally and hidden on the profile by default.

What works offline?

Profiles you previously opened and their downloaded game icons can be shown without a connection. np-track uses the latest saved snapshot and refreshes it after the device reconnects. Open Settings and select “Clear cache” whenever you want to remove saved profiles and game icons from this device.

Is live playtime exact?

While PSN reports that a user is playing, np-track advances the displayed total every five seconds as a local estimate. It periodically syncs back to PSN’s recorded total instead of sending an API request every five seconds.

How are trophy games ordered?

Completed trophy sets and earned trophies appear first by default. Enable “Keep PSN’s original trophy order” in Settings to preserve the order returned by PSN instead.

Which platforms and games are shown?

Platform marks are shown for PS3, PS Vita, PS4, and PS5 when PSN identifies them. Share Factory Studio is hidden by default so utility time does not affect lists or totals; it can be restored in Settings.

Can I open a game in the Store?

Current-game panels and Store links in game and trophy lists open the matching PlayStation Store concept page when PSN provides its identifier. Otherwise np-track opens a Store search for the title.
