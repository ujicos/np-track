Can it detect Appearing Offline?

np-track can show online status and the current game when PSN returns them. “Appearing Offline” is not exposed as a separate state, so it looks the same as being offline.

What is the NPSSO override?

The search page can use a temporary NPSSO value for one request. np-track does not save it, place it in the URL, or read from and write to shared profile cache while it is in use.

An NPSSO value is equivalent to a password. Only enter it on a deployment you control and trust.

Why can a renamed account fail?

Some Sony profile endpoints retain different name mappings after an online ID change. Add the previous ID in Settings so np-track can resolve the stable numeric account ID. Previous IDs are stored locally and hidden on the profile by default.

What does “NP” mean?

Sony uses NP throughout its network APIs and debug terminology, including NP environment and NP communication ID. It refers to the PlayStation network platform or network-service layer. Sony does not appear to publish a formal standalone expansion; PSN explicitly means PlayStation Network.
