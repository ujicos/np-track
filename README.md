# np-track

np-track is a simple PSN profile tracker for viewing playtime, game history, activity, and trophies. Compare profiles or combine playtime from the same game across multiple accounts.

## Features

- View a PSN profile, online status, and current game.
- See total playtime, first and last played dates, and a searchable game history.
- Sort games by playtime, recent activity, or title.
- Browse Top 10 games and detailed trophy collections.
- Compare two PSN accounts side by side.
- Combine full-account or game-specific playtime across multiple profiles.
- Find games by name, common aliases such as BO2, or exact PSN title IDs.
- Optionally combine linked PS4 and PS5 releases.
- Save a default profile and remembered Combine setup on your device.
- Install as a PWA and reopen previously viewed profile data while offline.
